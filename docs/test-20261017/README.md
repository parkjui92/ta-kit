설치한 플러그인으로 빈 프로젝트에서 `ta-scope`를 불러 G1까지 돌린 기록. 13주차 '게이트가 실제로 잡은 것' 사례로도 쓴다.

| 단계 | 결과 |
|---|---|
| 설치 | `claude plugin marketplace add <ta-kit 폴더>` → `claude plugin install ta-kit@ta-kit` — 스킬 7·에이전트 6 인식, 상시 비용 약 864토큰 |
| 헤드리스(`claude -p`) | 실행 못 함 — CLI 로그인 토큰 만료(401). 데스크톱 세션에서 스킬을 직접 불러 시험 |
| `ta-scope` 로드 | 정상(기본 폴더가 개발 폴더로 잡혀 수정이 바로 반영됨) |
| 조사관 `ta-kit:ta-scout` | 01_scope.md 1~7절 + 9절(리더 대신 고른 기본값) 작성, 약 5.6분·도구 45회 |
| 기계 점검 G1 | [필수] 1(리더 승인 — 예상된 미완). 점검기 오탐 1건 발견·수정(하위 목록으로 채운 '자료·위험'을 비었다고 판정) |
| 검수관 `ta-kit:ta-reviewer` | **보류** — [필수] 1: 정의에 '사람의 승인'을 조건으로 넣어 승인 없는 에이전트를 미리 뺌(GAO·OECD 원문은 '감독이 적은 쪽'이 에이전트의 특징). [권고] 7. 출처 대조 11건(직접 열람 9). 읽기 전용 지킴 |

## 시험에서 고친 것

- 조사관이 KISTEP 240쪽 보고서를 찾지 못하고 대중판 책자 보도자료만 봄 → `ta-scope`·`ta-scout`에 보고서 주소와 "책자·보도자료는 보고서를 대신하지 못함"
- 조사관이 정책 목표를 기본값 '두지 않음'으로 고름(그러면 옵션 단계가 빔) → GAO-25-107172 중립 짜임을 기본 후보로
- 가상 예시를 '사례'로, 요약 도구로 본 것을 원문처럼, 조문 항·호를 일부만 옮긴 것 → `ta-scout` 규칙 추가
- 정의 조건과 판단 기준이 겹친 것 → G1 기준에 ★ 한 줄 추가
