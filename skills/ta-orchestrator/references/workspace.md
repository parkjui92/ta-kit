# 작업 폴더 규약

평가 하나 = 폴더 하나. 기본 위치는 프로젝트의 `ta/`. 파일 이름은 영문(한글 파일명은 macOS·Git에서 깨지기 쉬움), 내용은 한국어.

| 파일 | 단계 | 만드는 역할 | 게이트 |
|---|---|---|---|
| `00_request.md` | 시작 | 리더 | — |
| `01_scope.md` | 범위 결정과 평가 질문 | 조사관 | G1 |
| `02_impact.md` | 영향 식별 | 정리관 | G2 |
| `02b_stakeholders.md` | 영향 식별 | 정리관 | G2 |
| `03_signals/S-YYMMDD-NN.md` | 지평 탐색(신호 카드) | 감시관 | G3 |
| `03_watch_YYMMDD.md` | 지평 탐색(주간 보고) | 감시관 | G3 |
| `04_evidence.md` | 증거 평가 | 분석관 | G4 |
| `05_options.md` | 정책 옵션 | 분석관 | G6 |
| `06_report.md` | 보고서 | 분석관(조립) | G5 · G6 |
| `07_panel_<형식>_YYMMDD.md` | 모의 패널 | 모의 패널관 | (G6 예행) |
| `gates/G<n>_YYMMDD.md` | 게이트 판정 | 검수관 판정을 리더가 저장 | — |
| `_log.md` | 전 과정 | 리더 | — |

## 원칙

- `00_request.md`는 의뢰 원문을 **글자 그대로** 둔다. 해석은 `01_scope.md`에서 한다
- 한 단계의 산출물은 다음 단계의 입력이다. 지난 단계 파일이 없으면 수업 공용 저장소의 시작 폴더에서 복사해 시작한다(한 주를 놓쳐도 시작할 수 있게)
- 모든 사실 문장에는 출처(기관·문서명·연도·URL 또는 쪽)를 단다. 출처 없는 문장은 근거가 아니다
- `〔리더 판단〕` 칸은 에이전트가 채우지 않는다. 영향의 중요도·신호 선정·게이트 승인은 사람의 일이다
- 모의 패널 결과(`07_*`)는 증거가 아니다. `06_report.md` 1~6장에 인용하지 않고 7장 '모의 검토'에만 적는다
