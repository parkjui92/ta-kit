# 증거 평가

GAO는 발견사항을 확정하기 전에 각 목표에 대해 **증거가 충분하고 적절한지** 판정하고 메시지에 합의한다(GAO-21-347G 부록 Ⅲ p.50). 증거는 증언·문서·물리 세 유형으로 나누고 유형마다 장단점이 있다(부록 Ⅳ p.52~56).

## 절차

1. **입력 확인** — `ta/01_scope.md`(질문), `ta/02_impact.md`(영향 행), `ta/03_watch_*.md`(선정 신호), 조사관이 모은 증거, 리더가 준 데이터
2. **템플릿 복사** — `templates/04_evidence.md` → `ta/04_evidence.md`
3. **분석관에게 맡김** — `ta-analyst`에게 다음을 지키게 한다
   - 증거 한 행에 수치·사실 하나. 유형과 성격을 표시
   - **자료분석**: 코드와 결과 파일은 `ta/analysis/`에. 출처 칸에 파일 이름과 실행 명령. 결과 파일에 없는 수치는 쓰지 않는다
   - 발견사항마다 근거 증거 번호, 충분·적절 판정과 이유, 불확실성(상·중·하 또는 시나리오, 모르면 "불분명함 — 이유")
   - 증거 유형 분포를 세고 쏠림을 한계에 적는다
4. **G4 게이트** — 기계 점검 `python3 ../ta-orchestrator/scripts/ta_check.py ta/ --gate G4` → `ta-reviewer` 판정 → `ta/gates/G4_YYMMDD.md`

## 리더에게 보일 때

- 발견사항 표와 '부족' 판정이 난 발견사항을 먼저 보인다
- 부족한 곳은 ①증거를 더 찾거나 ②발견사항을 약하게 고치거나 ③보고서 5장 '모르는 것'으로 옮길지 리더가 고른다

## 하지 않는 것

- 업체가 스스로 밝힌 수치를 측정치처럼 쓰지 않는다
- 모의 패널 발언을 증거로 넣지 않는다
