# 지평 탐색과 상시 모니터링

GAO는 2024년부터 정기 지평 탐색 보고서 「On the Horizon」을 내고(GAO-25-107542), 평가 중에도 주제 영역을 상시 모니터링해 맥락이 바뀌면 설계를 고친다(GAO-21-347G p.19·26). 유럽 기관의 지평 탐색은 모두 **신호 수집 → 의미 부여 → 우선순위**로 가고 선정은 사람이 한다.

## 절차

1. **입력 확인** — `ta/01_scope.md`, `ta/02_impact.md`(행 번호를 영향 영역으로 씀)
2. **감시 출처 정하기(리더와 함께)** — `templates/03_watch.md` 2절 표를 채운다. 출처마다 감시 주기를 다르게: 영향이 크고 변화가 빠른 곳(주요 기업 발표·규제 기관 공지)은 매주, 느린 곳(법령)은 사건이 있을 때
3. **한 번 실행** — `ta-watcher`에게 출처 목록과 기간을 주고 신호 카드와 주간 보고를 쓰게 한다. 카드 템플릿: `templates/signal_card.md`
4. **리더 선정(G3)** — 주간 보고 3절 후보 표를 보이고 한두 개를 고르게 한다(EU ESPAS는 약신호 약 20개 중 3개를 고름). 고른 카드의 상태만 `선정`으로 바꾼다. 나머지는 그대로 보관
5. **설계 재방문** — 보고 4절에 요청이 있으면 리더에게 범위·영향 행렬을 다시 볼지 묻는다
6. **기계 점검** — `python3 ../ta-orchestrator/scripts/ta_check.py ta/ --gate G3`

## 주기 실행(예약 작업)으로 바꿀 때

- 데스크톱 앱의 예약 작업에 아래 요청문을 등록한다(주 1회 권장)
  > ta-horizon으로 이번 주 감시 보고를 만들어줘. 선정은 하지 말고 후보까지만.
- **안전장치**: 쓰기는 `ta/03_signals/`와 `ta/03_watch_*.md`만. 메일·메신저 발송, 외부 게시, 다른 파일 수정을 하지 않는다. 실행이 실패하면 다음 실행이 이어받도록 보고에 '이번에 못 본 출처'를 적는다
- 무인 실행은 확인 없이 쌓인다. 리더가 매주 한 번 후보를 보고 고르는 시간을 정해 둔다

## 하지 않는 것

- 감시관이 신호를 고르지 않는다
- 검색 결과 요약만 보고 카드를 쓰지 않는다(출처 링크를 직접 열어 확인)
