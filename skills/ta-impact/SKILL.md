# 영향 식별

EU 영향 식별 도구의 3단계(식별 → 중요한 것 선택 → 평가) 가운데 **식별**을 빠짐없이 하고, **선택**은 리더에게 넘긴다(Better Regulation Toolbox Tool #18). 평가는 증거 평가 단계에서 한다.

## 절차

1. **입력 확인** — `ta/01_scope.md`(G1 승인)가 없으면 수업 시작 폴더에서 복사하도록 안내한다
2. **템플릿 복사** — `templates/02_impact.md`, `templates/02b_stakeholders.md` → `ta/`
3. **정리관에게 맡김** — `ta-mapper`에게 두 파일을 주고 다음 순서를 지키게 한다
   - 이슈를 먼저 모은다 → 핵심이슈로 묶는다 → 영향 영역과 시행령 항목을 붙인다(KISTEP 2024가 스스로 짚은 '시행령 항목대로 기계적으로 채우기'를 피함)
   - 같은 영역의 긍정·부정을 짝으로
   - 크기는 출처 있는 사실만, 중요도 칸은 `〔리더 판단〕`
   - 영향을 다르게 받는 집단(인공지능취약계층 등)을 이해관계자에 넣음
4. **(선택) 빈 관점 찾기** — 공백이 많으면 `ta-panel`로 시민 패널 예행을 돌려 빈 관점 후보만 받는다. 후보는 출처 칸에 `모의 패널 — 확인 필요`로 들어가며 크기를 채우지 않는다
5. **리더가 중요도를 매긴다** — 행 목록을 보이고 높음/중간/낮음을 받는다. 리더가 정하지 않은 칸은 그대로 둔다
6. **G2 게이트** — 기계 점검 `python3 ../ta-orchestrator/scripts/ta_check.py ta/ --gate G2` → `ta-reviewer` 판정 → `ta/gates/G2_YYMMDD.md`

## 리더에게 보일 때

- 시행령 항목별 행 수, 짝이 없는 영역, 공백 표를 먼저 보인다
- 영향 행렬 전체는 파일 경로로
